# Лабораторная работа № 1 — Метод Якоби

Реализация циклического метода Якоби для вычисления собственных чисел и собственных векторов действительной симметричной матрицы на Python 3.10+.

Программа использует только стандартную библиотеку Python. Для дополнительных сравнительных тестов требуется NumPy.

## Запуск

Из корневого каталога проекта:

```bash
python -m jacobi_eigen examples/matrix.json
```

Для матрицы 5×5 из методических указаний:

```bash
python -m jacobi_eigen examples/matrix_from_pdf.json
```

Дополнительные параметры запуска:

```bash
python -m jacobi_eigen examples/matrix.json --epsilon 1e-24 --max-sweeps 100
```

Параметры:

- `--epsilon` — порог суммы квадратов внедиагональных элементов над главной диагональю (по умолчанию `1e-24`);
- `--max-sweeps` — максимальное количество циклических проходов (по умолчанию `100`);
- `--no-sort` — не сортировать собственные числа по возрастанию.

Входной JSON-файл содержит матрицу или объект с ключом `matrix`:

```json
{
  "matrix": [[2, 1], [1, 2]]
}
```

Результат выводится в формате JSON: собственные числа, матрица собственных векторов, число проходов и поворотов, остаточная внедиагональная норма. Векторы соответствуют собственным числам по порядку и записаны **в столбцах** матрицы `eigenvectors`.

## Использование как библиотеки

```python
from jacobi_eigen import jacobi_eigendecomposition

matrix = [[4, 1, 1], [1, 3, 0], [1, 0, 2]]
result = jacobi_eigendecomposition(matrix)

print(result.eigenvalues)
print(result.eigenvectors)
```

Сигнатура функции:

```python
jacobi_eigendecomposition(matrix, *, epsilon=1e-24, max_sweeps=100, sort=True) -> EigenResult
```

Входная матрица должна быть непустой, квадратной, симметричной и содержать конечные вещественные числа, представимые типом `float`. Аргумент `epsilon` должен быть положительным конечным числом, `max_sweeps` — положительным целым числом, `sort` — логическим значением. Входная матрица не изменяется.

Возвращаемый объект `EigenResult` содержит следующие поля:

| Поле | Содержание |
|---|---|
| `eigenvalues` | Собственные числа |
| `eigenvectors` | Матрица собственных векторов (векторы в столбцах) |
| `sweeps` | Количество проходов |
| `rotations` | Количество поворотов Якоби |
| `off_diagonal_norm` | Остаточная норма внедиагональных элементов верхнего треугольника |

Предусмотрены исключения `InvalidMatrixError`, `InvalidParameterError`, `ConvergenceError` и `NumericalError` (наследуются от `JacobiError`). При недостижении заданной точности в пределах `max_sweeps` вычисление завершается ошибкой `ConvergenceError`.

## Алгоритм

В каждом циклическом проходе рассматриваются пары индексов `p < q`. Поворот зануляет элемент `A[p][q]`, обновляет соответствующие строки и столбцы рабочей матрицы и накапливает ортогональные преобразования в матрице собственных векторов. Вычисление завершается, когда сумма квадратов элементов верхнего внедиагонального треугольника становится меньше `epsilon`.

Для уменьшения риска переполнения при вычислениях используется масштабирование матрицы. Если представление входных данных или результата в `float` приводит к неприемлемой потере информации, генерируется `NumericalError`.
