# Лабораторная работа № 2. Свойства случайных матриц

## Описание

Исследуются расстояния между двумя фиксированными соседними собственными числами ансамблей действительных симметричных матриц размеров 2×2, 4×4, 16×16. Рассматриваются два распределения исходных элементов: стандартное нормальное N(0,1) и независимые равновероятные значения −1, +1. Каждая симметричная матрица имеет вид `A = X + X.T`.

Для каждого ансамбля:

- генерируются 10 000 матриц с фиксированным seed;
- собственные числа находятся с помощью `numpy.linalg.eigvalsh` и сортируются;
- измеряется один и тот же *центральный* промежуток для каждой матрицы размера n: между λ(n/2) и λ(n/2+1) при индексации от 1;
- промежутки нормируются на своё выборочное среднее;
- строятся гистограмма и функция Вигнера `p(s)=πs/2·exp(−πs²/4)`, а также сравниваются накопленные распределения;
- вычисляются доля практически нулевых промежутков и максимальное отклонение эмпирической CDF от теоретической CDF Вигнера.

В `Report_Lab2.pdf` находятся анализ гистограмм, математический вывод для размера 2×2 и выводы. Тесты проверяют корректность генерации, расчётов, нормировки и формул.

## Требования

Python 3.10+; NumPy и Matplotlib устанавливаются как зависимости проекта.

## Установка

Из папки с `pyproject.toml`:

```bash
python -m pip install -e .
```

## Запуск

```bash
python -m random_matrix_lab
```

Результаты сохраняются в `results/`: `summary.csv`, шесть файлов `spacings_*.csv` и шесть графиков в `results/plots/`.

Для другого объёма ансамбля или начального числа генератора:

```bash
python -m random_matrix_lab --count 10000 --seed 20261017 --output results
```

## Тестирование

```bash
python -m unittest discover -s tests -v
```

## Структура

- `src/random_matrix_lab/analysis.py` — генерация ансамблей, собственные значения и статистические функции;
- `src/random_matrix_lab/__main__.py` — командный запуск и сохранение результатов;
- `tests/test_analysis.py` — тесты;
- `results/` — воспроизводимые численные данные и графики;
- `Report_Lab2.pdf` — отчёт по заданию.

## Математические особенности

После симметризации `X + X.T` для нормальной исходной матрицы дисперсии диагональных и внедиагональных элементов равны 4 и 2 соответственно. Для исходных значений ±1 распределение симметризованной матрицы дискретное. В частности, для размера 2×2 величина промежутка до нормировки равна 0, 4 или 4√2 с вероятностями 1/4, 1/2 и 1/4. Поэтому совпадение с непрерывной формулой Вигнера для дискретного случая не требуется.

Гистограмма дискретных данных показана вместе с плотностью Вигнера исключительно для сравнения; её высоты зависят от ширины столбца. Сравнение CDF не зависит от бинирования.
